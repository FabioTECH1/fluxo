## Modifying and distributing Fluxo

When distributing covered versions, comply with AGPLv3's license, notice, and corresponding-source requirements. Distributed modified versions remain under AGPLv3.

If you modify Fluxo and users interact with that modified version over a network, you must prominently offer those users access to its corresponding source at no charge. A link to the original Fluxo repository alone is insufficient if it does not contain your modifications.

Commercial forks and hosted services are permitted when they comply with the license. AGPLv3 does not require submitting changes back to the official Fluxo repository.
